# .github: AEP org meta-repo

Org profile ([profile/README.md](profile/README.md), rendered on the
organization landing page) and the org-wide community health defaults
(`SECURITY.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`) that AEP
repositories inherit when they don't carry their own copy. The canonical,
full versions of the health files live in the standard repository,
[agent-event-protocol](https://github.com/agenteventprotocol/agent-event-protocol);
the copies here are pointers with the critical facts inline.

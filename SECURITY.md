# Security Policy (org-wide default)

This policy applies to every repository in the AEP organization that does not
carry its own `SECURITY.md`.

**Report vulnerabilities privately via the affected repository's Security tab
→ "Report a vulnerability"** (GitHub private vulnerability reporting). Do
**not** open a public issue.

The canonical policy — including redaction-pipeline defects being treated as
security vulnerabilities, the relay's trusted-network deployment scope, and
response expectations — lives in the standard repository:
[SECURITY.md](https://github.com/agenteventprotocol/agent-event-protocol/blob/main/SECURITY.md).
